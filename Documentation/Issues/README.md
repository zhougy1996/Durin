## Documentation Boundaries

- `Documentation/Issues` records current problems, evidence, impact, and candidate directions.
- `Documentation/Plans` records a selected implementation path with stages and acceptance gates.
- `Documentation/Architecture` records adopted behavior and long-lived constraints.

Informal research and candidate approaches belong outside version control under the ignored `Documentation/Local/` directory or in an external knowledge base. Repository documents must not depend on links to those local notes.

Read `AGENTS.md` in this directory before adding or restructuring an issue document. Update this index whenever an issue is added, renamed, resolved, or removed.
