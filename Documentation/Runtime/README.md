# Runtime

| Area | Purpose |
| --- | --- |
| [Core](Core/) | Process, module, reflection, object, and lifetime contracts |
| [Assets](Assets/) | Authored packages, derived data, storage, and versioning |
| [Animation](Animation/) | Skeletal pose evaluation, playback, and immutable palette publication |
| [World](World/) | Levels and world-facing systems |
| [Rendering](Rendering/) | Viewports, materials, textures, shaders, and caches |
